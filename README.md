## 📌 Project Overview

Student Performance Analysis is a Python-based data analysis project that explores students' academic performance using subject scores, GPA, attendance, daily study hours, and other student-related factors.

The project uses data cleaning, Exploratory Data Analysis (EDA), statistical analysis, and data visualization to identify patterns and relationships in student performance.

## 🎯 Project Objectives

- Analyze students' Maths, Reading, and Science scores.
- Calculate average scores and GPA.
- Examine the relationship between attendance and academic performance.
- Analyze the relationship between daily study hours and scores.
- Categorize students based on their academic performance.
- Present insights using charts and visualizations.

## 🛠️ Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset Description

The dataset contains student demographic information, academic scores, attendance, study habits, and other student-related factors.

**Key Columns:**

- Age and Grade
- Gender and School Type
- Maths, Reading, and Science Scores
- GPA
- Attendance Rate
- Daily Study Hours
- Internet Access
- Extracurricular Activities
- Parental Support

The analysis was performed on approximately **999,997 student records**.

## 🔍 Project Workflow

1. Load and inspect the dataset.
2. Check missing values and duplicate records.
3. Validate data types and values.
4. Clean the dataset.
5. Calculate average scores and GPA statistics.
6. Analyze performance categories.
7. Calculate correlations between attendance, study hours, and average scores.
8. Create visualizations.
9. Summarize the findings.

## 📈 Key Findings

- **Overall Average Score:** 74.98 out of 100
- **Average GPA:** 3.0 out of 4.0
- **Average Attendance Rate:** 89.96%
- **Attendance and Score Correlation:** 0.91
- **Study Hours and Score Correlation:** 0.51

### Performance Categories

- **Satisfactory:** 499,976 students (approximately 50.03%)
- **High Performance:** 499,279 students (approximately 49.96%)
- **Needs Improvement:** 39 students

### Key Insights

1. All three subjects had nearly identical average scores of approximately 74.98.
2. Attendance showed a strong positive relationship with average scores.
3. Study hours showed a moderate positive relationship with average scores.
4. Correlation indicates an association between variables but does not prove causation.

## 💡 Conclusion

This project demonstrates how Python can be used to clean and analyze student data, calculate statistical measures, identify relationships between variables, and present findings through visualizations.

The analysis suggests that attendance and study hours are positively associated with academic performance in the dataset. These findings demonstrate how data analysis can help identify patterns and areas where students may need additional academic support.
